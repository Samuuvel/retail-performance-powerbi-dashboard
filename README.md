# Retail Performance Power BI Dashboard

## Project Overview

This project analyzes retail sales performance using Power BI to uncover business insights related to revenue, profit margins, regional trends, and product performance.

---

## Tools & Technologies

* Power BI
* Power Query
* DAX
* Excel Dataset
* Data Cleaning
* Data Visualization

---

## Dashboard Features

* KPI Cards
* Revenue Analysis
* Profit Margin Tracking
* Region-wise Sales Analysis
* Product Category Performance
* Monthly Sales Trends
* Interactive Filters & Slicers
* Drill-down Analysis

---

## Data Modelling

* Star Schema
* Fact & Dimension Tables
* Relationships
* Data Transformation using Power Query

---

## DAX Measures Used

* Total Sales
* Profit Margin
* Quantity Sold
* Month-over-Month Growth
* Year-over-Year Variance

---

## Key Business Insights

* Identified top-performing product categories
* Detected underperforming regions
* Analyzed monthly revenue growth trends
* Improved visibility into sales KPIs
